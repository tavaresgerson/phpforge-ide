PHPForge IDE

PHPForge IDE is an integrated development environment (IDE) focused on PHP. It is a fork of the Apache NetBeans Platform, trimmed to a lean PHP development environment: PHP editing, debugging (Xdebug), framework support (Symfony, Zend, Nette, Doctrine, Twig and more), Composer integration and HTML/CSS/JavaScript tooling.

To start the IDE (Linux):

  • Run install-directory/bin/netbeans from the command line.

To stop the IDE:

  • From the IDE, choose File > Exit.

To uninstall the IDE

If you are using the ZIP distribution just delete the extracted folder.

After removing the IDE you might still have user and cache directories on the system that you may wish to remove (see below).

Documentation and sources

  • Project repository: https://github.com/tavaresgerson/phpforge-ide.
  • Based on Apache NetBeans: https://netbeans.apache.org/.

PHPForge IDE user / cache directories

A default user directory is created the first time you start the IDE. It is used to store your user settings, options and runtime data. In addition a cache directory is created to store various data used at runtime to speed up operation.

The locations of these directories can be found in the About-Dialog (Main-Menu: Help → About).

Microsoft Windows
The user directory is generally found at C:\Users\username\AppData\Roaming\NetBeans\version.
The cache directory is generally found at C:\Users\username\AppData\Local\NetBeans\Cache\version.
Unix-like
The user directory is generally found at $HOME/.netbeans/version.
The cache directory is generally found at $HOME/.cache/netbeans/version.
macOS
The user directory is generally found at /Users/username/Library/Application Support/Netbeans/version.
The cache directory is generally found at /Users/username/Library/Caches/Netbeans/version.
